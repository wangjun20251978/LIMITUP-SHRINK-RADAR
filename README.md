# 涨停缩量雷达

七日内涨停后放量缩量买股 · 首缩日收阳信号扫描。

**在线看板**：https://wangjun20251978.github.io/LIMITUP-SHRINK-RADAR/

每个交易日 4 档自动更新（12:30 / 14:50 / 16:30 / 20:10 左右），`index.html` 由扫描脚本
`limitup-shrink-scanner/scripts/update.mjs` 生成后自动推送到本仓库，GitHub Pages 即时生效。

## 口径

- 扫描池：近 12 自然日涨停过的股票
- 信号：涨停后（T）第 2~7 个交易日出现缩量，按「缩量比」排序
- **★最佳买点**：首缩日收阳（回测胜率最高的一档）
- 命中收阴：同样缩量但收阴，按回测口径提示回避
- 尾盘档（14:50）为预估口径，当日量按已交易分钟折算系数 ≈ ×1.04；收盘以 16:30 正式版为准
